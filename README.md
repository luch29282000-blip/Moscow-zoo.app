# Приложение «Московский зоопарк» (PWA)

Готовое кроссплатформенное приложение (Progressive Web App), которое устанавливается и работает на **iPhone (iOS)**, **Android** и **ПК (Windows / macOS)** без App Store и Google Play, открывается на весь экран с иконкой манула и работает офлайн.

## Что внутри архива
- `index.html` — главная страница приложения с мета-тегами для iOS и Android
- `styles.css` — адаптивный интерфейс (верхняя панель на ПК + нижний Tab Bar на смартфоне с поддержкой `safe-area` iPhone)
- `app.js` — логика покупки билетов со скидками/льготами, каталог из 18 животных, новости, генератор QR-кода и маршрут прогулки
- `manifest.json` — манифест устанавливаемого приложения (имя, тема, ярлыки быстрого доступа)
- `sw.js` — Service Worker для кэширования и работы без интернета
- `icons/` — иконки приложения (`192x192`, `512x512`, `apple-touch-icon.png`, `icon.svg`)

## Шаг 1. Публикация за 2 минуты (бесплатно, с HTTPS)
Для установки PWA на смартфон нужен HTTPS-адрес. Самый удобный способ — **GitHub Pages**:

1. Создайте новый публичный репозиторий на GitHub (например, `moscow-zoo-app`).
2. Загрузите все файлы из распакованной папки в корень репозитория (включая папку `icons/`).
3. Перейдите в **Settings → Pages**.
4. В разделе **Build and deployment** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты приложение станет доступно по адресу:
   `https://<ваш-логин>.github.io/moscow-zoo-app/`

*(Альтернатива без регистрации: перетащите распакованную папку на [app.netlify.com/drop](https://app.netlify.com/drop) — ссылка появится сразу).*

## Шаг 2. Установка как приложение на устройство

### iPhone / iPad (iOS)
1. Откройте ссылку в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Выберите **«На экран „Домой“»** → **«Добавить»**.

### Android
1. Откройте ссылку в **Chrome**.
2. Нажмите кнопку **«📲 Установить»** в шапке приложения (или меню `⋮` → **«Установить приложение»**).

### Компьютер (Windows / macOS)
1. Откройте ссылку в **Chrome** или **Edge**.
2. Нажмите значок установки в правой части адресной строки — приложение появится в меню «Пуск» / Launchpad как отдельное окно.

---

## Дополнительно: если нужен установочный файл `.apk` для Android
1. Опубликуйте сайт по Шагу 1.
2. Откройте [pwabuilder.com](https://www.pwabuilder.com/), вставьте вашу HTTPS-ссылку.
3. Нажмите **Package for stores → Android → Generate Package** — сервис автоматически соберёт готовый `.apk` / `.aab` на базе Trusted Web Activity (TWA).
